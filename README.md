## 🚀 Key Features

* **Universal Platform Support**: Download video and audio from 1000+ websites including YouTube, Twitch, TikTok, Instagram, Twitter (X), Facebook, and direct media streams.
* **4K, 8K & 60 FPS Ultra-HD**: Lossless video streams automatically merged with highest fidelity audio tracks using high-performance FFmpeg.
* **Turbo Multi-Segment Accelerator**: 16 concurrent HTTP connections saturate bandwidth for lightning-fast speeds.
* **Smart Audio Suite**: Extracts MP3/M4A audio with embedded metadata (Title, Artist, Album) and high-resolution thumbnail artwork.
* **IDM-Style Browser Integration**: Includes an extension for Google Chrome, Brave, and Microsoft Edge that intercepts downloads and sends them directly to the app.
* **Intelligent File Renamer**: Never overwrite existing downloads. Duplicate filenames are automatically numbered `(1)`, `(2)`, `(3)...`.
* **Cyberpunk Dark Theme**: Built with a bespoke neon-cyan and pink CustomTkinter interface with smooth animations and audio cues.
* **100% Free & Open**: Zero paywalls, zero license keys, zero ads.

## 🛠️ Quick Installation (Windows)

1. Go to the [Releases](https://github.com/BMONAx/b-m0n-Downloader/releases) tab.
2. Download **`b-m0n_Downloader_Setup_v4.8.exe`**.
3. Run the setup and start downloading!

---

## 🌐 Browser Extension (Chrome / Edge / Brave)

1. Open your browser and navigate to `chrome://extensions` or `edge://extensions`.
2. Enable **Developer mode** in the top right corner.
3. Click **Load unpacked** and select the `browser_extension` folder.
4. Any download or media link you capture will instantly trigger the b-m0n Downloader popup!
